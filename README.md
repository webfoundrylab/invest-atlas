# Invest Atlas

投資信託・ETFを中心に、NISA、個別株、経済・市場、資産形成まで扱う日本語の投資情報サイトです。

## 運営方針
- まずは無料の GitHub Pages で運営する
- 公的機関、取引所、運用会社、企業の一次資料を優先する
- 記事には情報確認日・出典・リスク・手数料を明記する
- 過去の実績と将来の成果を混同しない
- アフィリエイト等の広告が発生した場合は読者に明示し、報酬の有無で比較結果を歪めない
- 個別の投資判断を断定的に勧めず、情報提供と教育を目的とする

## 公開
GitHub Pages を GitHub Actions からデプロイする構成です。
公開URL: https://webfoundrylab.github.io/invest-atlas/

## 記事の追加と自動生成
- 記事情報の単一情報源は `article-index.json` です。
- 記事一覧はトップページが台帳から公開記事を読み込み、キーワード検索・カテゴリ階層（大・中・小）・タグの条件を組み合わせて絞り込めます。キーワード検索・カテゴリ・タグは記事一覧の上にまとめ、カテゴリ階層は親カテゴリの選択に応じて候補を表示します。タグはモーダルで一覧・検索・複数選択ができ、選択中のタグは検索欄の下に表示します。スマートフォンでは検索条件を開閉パネルにまとめ、「初めての方へ」も折りたたみ、ファーストビューを短くします。
- `article-index.json` の `categories` は `children` で大・中・小の階層を定義します。記事には `category`（大カテゴリ）、`subcategory`（中カテゴリ）、必要な場合のみ `topic`（小カテゴリ）を設定します。`tags` はカテゴリを横断する検索用のテーマです。
- デプロイ時に `scripts/build-site.py` がカテゴリ別の記事一覧ページを `categories/` 以下に生成します。記事ページにはカテゴリへのパンくずとツリーを追加し、カテゴリ一覧と同じ左サイドバー＋右本文の2カラム構成にします。狭い画面ではサイドバーを折りたたみ表示に切り替えます。トップページのカテゴリツリーはビルド時にHTMLへ生成し、記事台帳のJavaScript読み込みに失敗しても表示されるようにします。記事のないカテゴリページは `noindex` とし、サイトマップには公開記事のあるカテゴリページのみ登録します。
- デプロイ時に `scripts/build-site.py` が台帳を読み、`sitemap.xml` と `related-articles.json` を生成します。
- `scripts/validate-content.py` が記事ファイル、カテゴリ、関連記事候補、サイトマップを検証します。検証失敗時はデプロイを停止します。
- `related-articles.json` は関連記事候補の生成データです。各記事本文に表示する関連記事リンクは、読者にとっての関連性を確認して編集します。台帳に登録しただけで本文リンクが自動挿入されるわけではありません。

新記事を追加する際は、HTML記事を作成し、`article-index.json` に `slug`、`title`、`category`、`subcategory`、必要に応じて `topic`、`tags`、`summary`、`status`、`related` を登録してコミットしてください。中・小カテゴリを追加する場合は `categories[].children` の階層に登録し、既存の分類と重複しないIDを使います。公開前にActionsの検証結果を確認します。

## 管理
進捗の正本は [PROJECT-STATE.md](PROJECT-STATE.md) です。新しい作業を始める前に最新状態を確認してください。



## 複数タグ・検索条件・関連記事の生成
- `article-index.json` の `tags` は文字列配列です。記事のテーマを具体的な複数タグに分け、表記をできるだけ統一します。
- トップページのキーワード検索は空白区切りで複数語を指定でき、OR（いずれかを含む）とAND（すべてを含む）を切り替えられます。対象はタイトル・概要・タグです。
- タグはモーダルダイアログで一覧・検索し、複数選択できます。タグ選択もOR（選択タグのいずれかを持つ記事）とAND（選択した全タグを持つ記事）を切り替えられます。キーワード検索・カテゴリ絞り込みとの併用も可能です。
- デプロイ時に `scripts/build-site.py` が台帳の `related` を優先し、共通タグの重なりを使って関連記事候補を補完します。公開記事HTMLに関連記事セクションを生成します。
- 自動補完はタグの質に左右されるため、記事のタグと `related` は編集時に確認してください。


## トップページの記事検索・絞り込み
- キーワード検索、カテゴリ（大・中・小）、タグ選択を記事一覧の上に集約。
- カテゴリは階層ごとに「すべて」を左端に置き、親カテゴリの選択に応じて次の階層の候補を表示。各行は横スクロール式で高さを固定し、選択によって記事一覧の位置が上下しないようにする。
- タグはモーダルダイアログで一覧表示し、タグ名検索・複数選択・選択解除に対応。選択中タグは記事一覧の上にも表示する。
- 記事は更新日が新しい順で表示し、公開日・更新日を併記。


## カテゴリ階層の表示ルール
- 最上位カテゴリは初期表示する。中位カテゴリは最上位で特定のカテゴリが選ばれ、その配下に候補がある場合のみ表示する。最下位カテゴリも同様に、中位カテゴリが特定され、配下に候補がある場合のみ表示する。
- 各階層の「すべて」はその階層の候補内で左端に表示し、上位階層の選択を維持したまま下位階層だけ解除できる。
- 「大・中・小」の文字ラベルは使用せず、段階ごとのインデント・ボタンサイズ・背景色で階層を表現する。非表示の行はスペースを確保し、記事一覧の位置が上下しないようにする。


## 記事サムネイルと一覧表示
- 公開記事のサムネイルは `thumbnails/` のSVG画像を使い、`article-index.json` の各記事に `thumbnail` パスを登録します。
- トップページの記事カードにはサムネイル・カテゴリ・タイトル・概要を表示します。画像は遅延読み込みし、モバイルでは小さな正方形に切り替えます。
- 公開日・更新日は、更新日を色付きラベルで強調し、公開日と視覚的に区別します。
- キーワードとタグの検索カードは入力欄、ボタン、選択中タグの余白を縮め、縦の占有量を抑えます。


## 検索フィルターの配置調整
- キーワード欄の重複した説明ラベルを省き、見出し「キーワード」と入力欄のプレースホルダーで案内する。入力欄にはアクセシブルな名前を設定。
- 複数ワードのOR/AND選択を、可能な範囲で見出しと同じ行に収め、幅が狭い場合は自然に折り返す。
- タグの「選択解除」をカード見出しの右上に配置。選択中タグのチップ一覧はカード下部に維持。


## 記事内容の整合性確認
- 制度や公的機関の名称・リンクは、確認時点の公式情報に合わせて更新します。
- 2026年10月時点のNISA解説には、2027年1月から予定されている未成年者のつみたて投資枠の変更を明記します。
- 2026年4月に統合した資産運用業協会の名称と公式資料リンクを使用します。
