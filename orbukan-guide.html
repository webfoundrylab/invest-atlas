2. 指数ごとの違いを先に確認する

オルカンはMSCI ACWI、楽天・全世界株式インデックス・ファンド（楽天・VT）と米国ETFのVTはFTSE Global All Capを採用しています。FTSE Global All Capは小型株まで対象に含むため、MSCI ACWIより企業規模の面でカバー範囲が広い点が違いです。ただし、対象範囲の広さが将来の成績の優位性を意味するわけではありません。

指数の仕組みや大型株・中型株・小型株の違いを先に整理したい方は、「全世界株式とは？MSCI ACWIとFTSE Global All Capの違い」をご覧ください。

4. 費用を比べるときの注意点

信託報酬・経費率だけを見て、単純に安い順に並べるのは十分ではありません。投資信託では、信託報酬以外の費用や、海外ETFを組み入れる場合の費用が実質コストに影響することがあります。過去の運用報告書で費用明細や指数との連動差も確認しましょう。

  • 同じ基準日で比較する：信託報酬の改定、実質コスト、総経費率は資料の基準日・対象期間をそろえます。
  • 指数との連動差も見る：費用が低くても、実際のファンドの値動きが指数と完全に一致するとは限りません。
  • 買う場所も確認する：取扱い証券会社、積立設定、最低購入金額、NISAの対象枠などは商品や販売会社によって異なります。

信託報酬と実質コストの見方は、「投資信託の信託報酬とは？」と「投資信託の実質コストとは？」で詳しく解説しています。

5. 比較の進め方

候補を絞るなら、まず①指数（MSCI ACWIかFTSE Global All Capなど）、②投資対象の範囲、③費用と指数との連動差、④積立や売買のしやすさ、⑤分配金・税務、⑥自分の口座での取扱い、の順に確認すると整理しやすくなります。すべての項目で一番のファンドが一つに決まるわけではありません。

6. 共通するリスクと注意点

  • 株式市場の下落：世界に分散していても、株式市場全体の下落で基準価額や市場価格が下がることがあります。
  • 米国株への比重：時価総額を反映する指数では米国株の比重が高くなることがあります。各国に均等に投資する商品ではありません。
  • 為替変動：海外資産を含むため、円高・円安が円換算の評価額に影響します。
  • 指数との連動差：費用や売買、現金保有などの影響で、ファンドやETFの値動きが指数と完全に一致するとは限りません。
  • 商品固有の条件：費用、分配方針、取扱い口座、税務上の扱いなどは商品・制度によって異なり、変更される場合があります。

全世界株式は、地域を分散する考え方であり、元本や利益を保証するものではありません。近い将来に使うお金を避け、値下がりしても生活に支障のない金額か、投資期間やリスク許容度に照らして考えましょう。

分散投資で抑えやすいリスクと残るリスクは、「分散投資とは？」と「投資のリスクとリターンとは？」も参考になります。

7. よくある質問

FTSE Global All CapのほうがMSCI ACWIより優れていますか？

一概には言えません。FTSE Global All Capは小型株まで対象に含むため、企業規模の面でカバー範囲が広い指数です。ただし、対象が広いことと、将来の運用成績が高いことは別です。

楽天・VTと米国ETFのVTは同じですか？

同じではありません。楽天・VTは日本の投資信託で、VTなどの海外ETFを実質的な投資対象として運用します。VTは米国市場に上場しているETFです。購入・換金方法や費用、分配金の扱いなどが異なります。

オルカンと楽天・プラス・オールカントリーは何が違いますか？

どちらもMSCI ACWIへの連動を目指す商品ですが、別の投資信託です。信託報酬だけでなく、その他費用、運用報告書で確認できる実質コスト、指数との連動差、販売会社での取扱いなどを同じ基準日で比べましょう。

オルカン以外の全世界株式ファンドも買う意味はありますか？

同じ指数に連動する商品を複数保有しても、投資先は大きく重なることがあります。商品を増やすこと自体よりも、何を補いたいのか、費用・運用方法・口座の使いやすさに違いがあるかを確認しましょう。

どれを選べばよいですか？

一つの正解があるわけではありません。指数の対象範囲、費用、積立や売買のしやすさ、分配金、税務、口座での取扱いを確認し、自分の運用方針に合うかで考えます。本記事は特定商品の購入を勧めるものではありません。
